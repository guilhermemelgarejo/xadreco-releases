# Xadreco — instaladores e atualizações

Instaladores oficiais do Xadreco para Windows 10 e 11 x64. O código-fonte é mantido em um repositório privado.

## Instalar

Acesse a [versão mais recente](https://github.com/guilhermemelgarejo/xadreco-releases/releases/latest) e baixe `Xadreco_<versão>_x64-setup.exe`.

A partir da versão 0.2.0, o jogo avisa quando existe uma nova versão e permite atualizar com sua confirmação. Quem usa 0.1.5 ou anterior precisa instalar a 0.2.0 manualmente uma vez.

O instalador baixa o WebView2 automaticamente caso o componente esteja ausente. Após instalar, o aprendizado e as partidas locais funcionam sem internet.

## Progresso

Os perfis e o progresso ficam na máquina do jogador. Antes de atualizar pelo jogo, o Xadreco cria uma cópia dos dados na pasta local de backups.

Você também pode exportar e importar backups em **Meu perfil**.

Os arquivos `.sig` e `latest.json` permitem ao aplicativo verificar a autenticidade das atualizações.
